Connect Google Analytics

One-time setup — your credentials are stored securely in your browser's IndexedDB and never leave your device.

1

Create a Service Account

Go to Google Cloud Console → Service Accounts. Create a new service account, then go to Keys → Add Key → JSON. A .json file will download.

2

Enable the GA4 Data API

In the same project, go to APIs & Services → Enable "Google Analytics Data API".

3

Grant Access in GA4

Go to GA4 → Admin → Property Access Management. Add your service account email as a Viewer.

4

Get Your Property ID

In GA4, go to Admin → Property Settings. Copy the numeric Property ID (e.g., 123456789).
